## 下一批优先顺序

1. 跟进首轮 GitHub Actions 与真实安装包问题，完成 Windows/macOS/Linux 启动和关键原生文件操作验证。
2. 补齐 M1 规则和多窗口、M2 任务状态/冲突交互、M3 节点合并等首版之后的重点。
3. 再推进 M4/M5，保持同一工作区和独立引擎结构。

## 持续约束

- 默认离线、本地，无服务端和账号要求。
- 不人为限制标签、会话、历史容量、目录项目或文件大小。
- 对真实资源不足或不支持的格式给出明确错误；不把近似、跳过或解析损失显示为精确相同。
- 原文、编码和文件写入保护优先于忽略规则的便利性。
- 安装包、截图及平台验收状态均以实际产物为准。
